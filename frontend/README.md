# ThinkTank Web Interface

React 19, TypeScript, Vite, and Tailwind CSS mission-control frontend for the ThinkTank multi-agent orchestration platform.

## Getting Started

```bash
npm install
npm run dev
```

The frontend will run on `http://localhost:5173` and proxy WebSocket connections and API calls to the backend on `http://127.0.0.1:8001`.

For complete system setup and operational instructions, see the [Main Project README](../README.md).
