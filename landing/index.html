The Solitary Model Fallacy

Why Single LLMs Fail

When a single model generates plans in isolation, it nods to itself. It has no adversary to puncture its assumptions, no auditor hunting for fallacies, and no counter-weight to verify citations.

The Solitary Prompt (ChatGPT / Claude)

The Echo Chamber

Single-agent workflows suffer from inherent confirmation bias. Once an LLM picks an angle, it defends it with cheerful sycophancy.

  • Unchallenged Assumptions: Never stress-tested against opposing models or edge cases.
  • Compounding Hallucinations: One slight mistake early in generation distorts the entire action plan.
  • Astronomical API Invoices: Metered token rates punish deep exploration and long multi-turn contexts.
The ThinkTank Dialectic

Adversarial Synthesis

ThinkTank pits distinct frontier models against one another. Ideas are proposed, ruthlessly dismantled, and rebuilt until they reach mathematical convergence.

  • Active Fallacy Hunting: Critics explicitly tag [FALLACY] Sunk Cost, [FALLACY] Survivorship Bias, etc.
  • Mathematical Convergence: Debates loop automatically until Severity Score ≤ 3 and Confidence > 85%.
  • Zero API Token Costs: Powered by persistent browser sessions in DeepSeek, Qwen, and GLM.

ADVERSARIAL CONVERGENCE LOOP

The Adversarial Debate

A visionary Proposer puts forward a strategy. A ruthless Critic hunts for architectural flaws and logical fallacies. If severity remains high, the Proposer must adapt. Once convergence metrics are met, a Synthesizer builds the executive roadmap.

1
DeepSeek R1 (Proposer): Formulates visionary thesis with confidence score.
2
Qwen 2.5 (Critic): Flags fallacies and assigns severity score (1-100).
3
GLM-4 (Synthesizer): Produces finalized executive summary and action items.
Proposer · Turn 1
"Propose introducing dynamic pricing tiered by behavioral loyalty metrics to increase customer retention..."
Critic · Turn 1
"[FALLACY: Survivorship Bias] The proposal assumes top-decile buyers represent the general population. Penalty risk will trigger a 34% churn spike."
Synthesizer · Convergence
"Executive Summary: Adopt non-punitive tiering. Reward frequency over total spend, insulating against churn while retaining margin."
Engineering Rigor

Under the Hood

ThinkTank is not another wrapper around OpenAI API credits. It is a full-fledged automation and vector synthesis runtime.

Stealth Browser Engine

Powered by Playwright and playwright-stealth, ThinkTank launches persistent Chromium contexts that store your active sessions securely on your local disk. Zero API keys. Zero metered token consumption.

FILE: backend/automation.py

Self-Healing JSON Engine

Consumer web portals love returning conversational fluff. ThinkTank forces responses into <THINK_JSON> tags, repairs malformed syntax with json-repair, and fires automated retry turns if validation fails.

FILE: backend/json_utils.py

ChromaDB Knowledge RAG

Upload PDF strategy guides, books, and dossiers. PyMuPDF strips front/back matter noise, chunks text semantically, and stores embeddings in ChromaDB. Models are required to provide page-level citations: [Book, Page X].

FILE: backend/memory.py
CO-PILOT REVIEW PROTOCOL

The CEO Directive

Autonomous loops are dangerous without executive oversight. With ThinkTank's Co-Pilot Mode enabled, the async coroutine suspends after each turn, allowing you to inspect arguments, inject counter-instructions, or steer the debate.

Local Deployment

Ready in 60 Seconds

Clone, activate your virtual environment, and run the Windows Proactor-safe server.

BASH / POWERSHELL
# 1. Clone the repository
git clone https://github.com/Mackming/thinktank.git && cd thinktank
# 2. Setup backend virtual environment & install requirements
cd backend && python -m venv venv && .\venv\Scripts\Activate.ps1
pip install -r requirements.txt && playwright install chromium
# 3. Start the backend runtime
python run.py
# 4. In a second terminal, start the React 19 UI
cd ../frontend && npm install && npm run dev
